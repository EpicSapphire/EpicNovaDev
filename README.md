## 💎 The Nova Core

Epic Nova uses three primary currencies:

* **Nova Bits** – Common
* **Nova Shards** – Rare
* **Nova Cores** – Premium supporter currency

During Early Access, Nova Cores help support development while profile and wallet systems are being built.
